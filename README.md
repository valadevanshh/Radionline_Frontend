# Radionline Frontend

Next.js app for RadioNet PACS.

## Setup

```bash
npm install
cp .env.example .env.local
# edit NEXT_PUBLIC_API_URL if needed
npm run dev
```

Runs on http://localhost:3000. Expects the API at `NEXT_PUBLIC_API_URL` (default http://127.0.0.1:8000).
